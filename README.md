# SpendWise – Make SpendWise Interactive

## Project Overview
SpendWise is a personal expense-tracking application designed to help users manage and monitor their daily expenses. This week's improvements focus on making the application interactive using JavaScript, DOM manipulation, arrays, conditionals, and event handling.

## Improvements Made This Week
The following improvements were made to SpendWise:

- Added JavaScript functionality to make the application interactive.
- Used arrays to store and manage expense records.
- Added conditional statements to make decisions based on user input.
- Implemented DOM manipulation to dynamically update content on the webpage.
- Added event listeners to respond to user interactions.
- Improved the overall user experience by making the application more responsive.

## How Conditionals Are Used
Conditional statements (`if`, `else if`, and `else`) are used to make decisions in the application.

For example, they can check whether an expense amount is valid before adding it or display an appropriate message when the user enters incorrect information.

## How Arrays Are Used
JavaScript arrays are used to store multiple expense records in one variable.

For example:

```javascript
let expenses = ["Lunch", "Transport", "Shopping"];
```

Arrays make it easier to add, access, and manage expense information.

## How the DOM Is Updated
The Document Object Model (DOM) allows JavaScript to interact with HTML elements.

Methods and properties such as:

- `document.getElementById()`
- `textContent`
- `innerHTML`

are used to select HTML elements and dynamically update the content displayed to users.

## How User Interactions Are Handled Through Events
JavaScript event listeners are used to respond to user actions.

For example:

```javascript
button.addEventListener("click", function() {
    // Handle user interaction
});
```

This allows the application to respond when users click buttons, submit information, or interact with different elements.

## Challenges Encountered and Solutions
During development, some challenges included:

These challenges were addressed through practice, testing, debugging, and reviewing JavaScript concepts.
